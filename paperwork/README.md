# 紙本比較組自學工作紙（材料 v7）

最新研究條件：實驗組使用 IBL＋VL；比較組沒有課前講授、不操作 VL，只靠 WS 自學。兩組活動總時間均為 **15–20 分鐘**；同一班次由研究者選定相同的總時間 T，包含閱讀、練習及核對修正。這個條件取代舊紙本的「先探究、最後揭示概念」。

## 教師入口與派發

指定教師登入後，按「下載紙本比較組自學工作紙 PDF」。可選繁中／英文，預覽及直接下載各冊／完整套裝，不需先完成示範或解鎖雲端學生資料。面板顯示 WS 題目版本、材料版本及 VL 來源版本。

| 冊 | 頁數 | 完整套裝頁碼 | 內容／派發 |
| --- | --- | --- | --- |
| A | 2 | 1–2 | A1 四行情境、六項補充資料、精簡方法／示例及乳化圖；A2 水解圖、設定及全部六組資料；全程可參閱 |
| B | 4 | 3–6 | B1–B2 有提示練習；B3–B4 獨立應用，涵蓋四組主實驗及兩組煮沸延伸 |
| C | 1 | 7 | 完成 B 並保存首次答案後才派；核對全部答案與另色修正，不擦除原答 |
| D | 8 | 8–15 | 教師指引、完整答案、15 行逐題配對表及紙本練習回饋準則；不派學生 |

學生材料共 7 頁；完整教師套裝共 15 頁。姓名／班別欄只在 A、C 首頁。所有文字回答各兩行；選項填空在句內圈選，多選用方格；裝置題補全給定圖的標示，不再要求學生自主繪畫原始設計。學生使用中性名稱「脂質的消化與公平比較」。

## 解說、示例及練習

A1 以四行交代情境，概念整理為六項可查閱的補充資料，並提前教 X＝膽汁（肝製造、膽囊儲存、無消化酶）、乳化與表面積、Y＝脂肪酶、甘油三酯完全水解簡化模型、高溫酶變性、冷卻至共同 37°C、外觀與直接產物證據的分別。物理圖保留分子不變；化學圖有三個分開的脂肪酸分子與置中箭頭標示。

示例教可測試性、變量分類及觀察／解釋差異；B 再評析另一個給定預測與錯誤理由，不假裝建立已學過答案的原始假說。其他題保留或等值改寫分類、實驗前提、對照、補全標示、不公平設計評析、六組外觀、三項結論、熱處理解釋及具體比較的概念運用。十五項練習的配對、共同目標與理由在 D；另有自動產生的 [逐題配對表](generated/mapping.md)。

所有基本組起始油水量、加液總量（2 mL）、37°C、觀察時間及搖勻方式相同。四組配方為水 2 mL、X 2 mL、Y 2 mL、X＋Y 各 1 mL。起始油水量、觀察時間及搖勻細節使用共同程序，不捏造模型沒有提供的數值。

目前模型六組外觀：水分層、X 混濁、Y 油層變薄仍分層、X＋Y 清澈；煮沸 X＋未煮沸 Y 清澈，未煮沸 X＋煮沸 Y 混濁。熱處理均先冷卻至共同 37°C，參照未煮沸 X＋Y。全部實驗圖集中於 A2：圖 1 四組主實驗，圖 2 未煮沸基準及兩組熱處理。B 依圖號自行記錄外觀，圖中不預填外觀分類答案；核對答案放 C／D。

清澈不能單獨證明甘油／脂肪酸形成，也不能量化速度；單獨組與合併組的個別試劑量不同，不能定量證明協同作用或速率提升。對照隨具體問題選擇，熱處理的對照本身含 X 與 Y；不沿用「所有對照完全沒有自變量」的概括說法。

## 15–20 分鐘及教師介入

| 階段 | T 比例 | 15 分鐘方案 | 20 分鐘方案 |
| --- | --- | --- | --- |
| A 補充資料、示例＋實驗圖 | 30% | 4.5 | 6 |
| B1–B2 有提示練習 | 35% | 5.25 | 7 |
| B3–B4 獨立應用 | 25% | 3.75 | 5 |
| C 核對修正 | 10% | 1.5 | 2 |

先按班級閱讀速度選定共同 T；兩組同一時限，記錄現場實際起止時間。比例是排程方案，並非已證明每名學生都能在該時段完成的研究結果；正式使用前在 15–20 分鐘範圍內試用核對。不能替比較組額外加課前講授或延長總時間。

開始只說明閱讀、作答與時間。B1–B2 可澄清文字／程序並指向 A，但不給答案；B3–B4 可閱 A，教師只處理程序與可及性，不給答題回饋。額外澄清要記錄並依共同支持規則處理兩組。核對時先保存 B，再發 C，按 C 作一致短回饋，保留首次與修正答案。

## 評分與研究成效

D 的紙本練習回饋滿分 **36**，逐題提供人工判準。它是本套 WS 的形成性活動評分，不等同 VL 的原始預測、虛擬操作、完成或 32 分活動 rubric，也不換算為 SPSAI／CKT。成效用兩組另行共同測驗評估。

評首次 B 答案；C 修正另留作學習證據，不回填首次分數。缺答保留未提供並依研究規則處理，不捏造；開放題看解釋與資料連結，不以關鍵字計分。紙本不產生操作事件、點擊、系統用時或虛擬實驗能力分數，也不寫入現有教師 Excel。

## 來源、版本、產生及驗證

`source.js` 只讀當前 VL 題目、圖像及 `VL1InquiryContent()`；`curriculum.js` 定義紙本專用的雙語解說、題目、答案、目標、配對和時間；`render.cjs` 依同一模型產生 A–D。VL 問題／資料版本仍是 `VL1-ui3-paper2`，WS 題目版本是 `VL1-WS-direct-2`，材料是 v7；學生 VL 的 IBL、紀錄、雲端和舊資料邏輯保留。

產生前核對六組模型；模型／配方／參考結論變更時要求審閱教材。來源 fingerprint 包括當前程式、紙本來源／版型、圖像及字型。更新材料後產生 PDF、source.json、manifest 和 mapping.md，移除舊版受管理 PDF。教師入口以 no-store 取 manifest／PDF，核對題目／材料／VL 版本、流程、來源 digest、PDF 格式、長度及 SHA-256，拒絕過期或損壞材料。HTML 的教材腳本與翻譯採新快取版本。

```bash
npm ci
npx playwright install chromium
npm run paper:build
npm run paper:check
python3 tests/paperwork_pdf.py
python3 -m http.server 8000 --bind 127.0.0.1
# 在另一個終端：
node tests/paperwork.cjs http://127.0.0.1:8000
node tests/language.cjs http://127.0.0.1:8000
node tests/smoke.cjs http://127.0.0.1:8000
```

Node >=20；PDF 檢查需 PyMuPDF 1.26.6。隨附 SIL OFL 授權 Noto HK 子集，外部 SVG 的系統 fallback 建議 Noto CJK。有 `/usr/bin/chromium` 時直接使用，其他路徑設定 CHROMIUM_PATH。CI 檢查已提交材料及重新產生的實際 PDF，不自動寫回 main 或更改 Pages 設定。

測試檢查兩語題目與完整六組、概念提前、示例不填全部結果、延後核對、逐題配對／評分、15–20 配對排程、字型、圖片、分頁、兩行作答、灰階外觀與三脂肪酸圖。瀏覽器測試實際下載十份 PDF 及預覽，拒絕舊／壞版本，確認前後學生答案、儲存、事件、計時、示範及實際 Excel 位元組一致。測試不連線真實 Google 收集端。教師入口不是額外 Google 身分驗證；空白教學材料亦不包含學生資料。

## v7 的呈現方式與研究條件

參考 DSE 情境實驗長題的閱讀節奏：四行情境→精簡補充資料→實驗設定／圖像資料→分題作答。這是呈現方式的調整；比較組仍以 WS 自學，核心概念及已解說示例從開始可閱，沒有改成未知答案的 IBL 探究。字數縮減採精簡與查閱式排版，不刪膽汁、表面積、水解、變性或證據限制。

十五項練習、共同 SPS／內容目標、36 分練習準則、B 首答與 C 修正分開、共同 15–20 分鐘、另行共同成效測驗均保留。DSE 類似的版面本身不代表難度／效度已驗證；仍需按共同時間小規模試用，以確認閱讀及作答負擔。

產生時驗證中英文開場實際只佔四行。六組資料只在 A2 集中呈現，B 題目引用 A2 圖 1／圖 2，避免重複印圖。學生 VL、模型與紀錄功能不修改。
