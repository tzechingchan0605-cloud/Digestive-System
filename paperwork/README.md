# 教師下載紙本對照組工作紙

依研究 proposal 4.1／4.3.2：兩組使用相同情境、概念和問題；紙本以靜態圖與預先製作的資料表代替互動模擬，活動在正式授課前完成。每週工作紙與正式 10 題 SPSAI／4 題 CKT 前後測分開。

## 教師使用

以指定教師電郵登入，點擊儀表板「下載紙本對照組工作紙 PDF」。不必先解鎖雲端學生資料或完成示範。面板可選繁中／英文、預覽及直接下載分冊／完整 PDF；材料語言預設跟隨當時介面，變更材料語言不切換探究語言。

| 分冊 | 頁數 | 完整套裝頁碼 | 派發安排 |
| --- | --- | --- | --- |
| A：情境與原始探究設計 | 3 | 1–3 | 先派，保存原始假說、理由及設計；學生保留副本 |
| B：實驗資料、分析與結論 | 2 | 4–5 | A 固定保存後派；基本資料／記錄／三題結論在前，熱處理在後 |
| C：學習重點及反思 | 2 | 6–7 | 固定／收取原探究答案後才派，反思參閱原始假說副本 |
| D：教師指引、答案及評分準則 | 7 | 8–14 | 只供教師，不派學生 |

中英文各有五份真正 PDF：A、B、C、D、完整教師列印套裝（14 頁）。學生只需 A–C（7 頁）；完整套裝不能整套一次派學生。界面顯示各冊在完整套裝中的頁碼範圍。PDF 只在 A、C 首頁各印一次姓名／班別及學號空白欄，另保留版本及頁碼；不帶入真實學生或教師資料。

所有原有題幹、選項與提示來自 VL；句子填空的下拉選單轉為句內括號選項，學生圈選每組一項；文字作答及修訂欄統一為兩條橫線。三類變量各有七個可複選因素；裝置繪圖在文字欄之前。基本外觀提供四項選擇，熱處理提供兩項，與 VL 相同。B 的表格只預印條件與外觀圖，觀察判讀欄保持空白。修訂欄不新增評分題，第一次確認的觀察須保持可讀。

灰階列印仍以層厚、明暗和紋理區分六組結果；印刷機設定可能改變明暗，正式派發前請試印 B。使用同一語言及相同可用時間；proposal 未規定單次活動分鐘數，不能把網站提示當作研究已明定的時長。

教師以相同答案與 rubric 批改紙本；D 的「自動」是共用 VL Excel rubric 的原有說明，不代表能自動辨識手寫答案。六項 SPS 共 24，新知識 8，活動總分 32 的初稿仍需校準；合理可測試假說不能因預測錯誤扣分，時間／完成率／點擊不能直接換能力分數。

## 內容來源及自動產生

`source.js` 只讀現有題目 DOM 的原文及 `VL1InquiryContent()` 提供的變量、前提、六組預設結果、參考答案與 Excel rubric；不讀學生欄位值、session、localStorage 或雲端資料。中英文使用現有 `VL1Language.text(value, language)` 映射，不需要切換目前介面。

`build.cjs` 在隔離瀏覽器中封鎖 Google 收集端與外部字型，從上述同一來源產出 A4 PDF。字型採 SIL OFL 授權的 Noto CJK 香港字形子集，隨材料程式提供；PDF 保留字形、向量圖及可選取文字，不是長截圖。字型授權見 `fonts/LICENSE.txt`。

安裝及重新產生：

```bash
npm ci
npx playwright install chromium
npm run paper:build
npm run paper:check
python tests/paperwork_pdf.py
```

Node >=20；PDF 檢查需 `PyMuPDF==1.26.6`。外部 SVG 的系統 fallback 建議安裝 Noto CJK 字型；Linux 可安裝 `fonts-noto-cjk`。環境已有 `/usr/bin/chromium` 時可直接使用；其他路徑設定 `CHROMIUM_PATH`。

更新題目、翻譯、圖像或列印模板後，重新產生並提交 `generated/` 中 PDF、來源快照及 manifest。空白 PDF 由生成程式自動產生，不手改另一份問題。若新增作答欄，生成程式會要求更新題目／版面對應；英文教師 rubric 若項目數改變也會阻止產生，避免默默缺題。

同一紙本版本的選項位置固定；前提的錯誤選項在第二位，客觀題的錯誤位置分散。VL 每次探究的隨機順序保留，兩者使用同一選項內容及 ID。manifest 記錄順序、來源 fingerprint、頁數、頁碼範圍、檔名及 PDF SHA-256。

`paper:check` 驗證版本來源與 PDF 完整性。教師面板亦比對當前題目內容 digest，下載時再驗證 PDF checksum；舊版或損壞材料會拒絕下載並提示重建。CI 驗證已提交材料並重新產生材料供 artifact 審閱。此 workflow 不改 GitHub Pages 設定或自動寫回 main；更新發布版本須提交生成檔案，既有 Pages 流程會隨儲存庫更新提供下載。

## 隔離與測試

材料入口沿用目前教師帳戶規則，所有預覽／下載函式檢查教師模式；這不另外構成 Google 身份驗證。空白 PDF 為靜態教學檔案，與學生紀錄及雲端密碼分開。

```bash
node tests/paperwork.cjs http://127.0.0.1:8000
python tests/paperwork_pdf.py
npm run paper:check
```

瀏覽器測試封鎖真實雲端連線，驗證目前題目／選項、十份 PDF 的實際下載與檔名／checksum、教師入口、預覽、獨立語言選擇、版本不一致／損壞處理、手機版，以及下載前後 localStorage、作答、計時、事件、示範及實際 Excel 一致。下載點擊採正常間隔，避免 Chromium 對連續大量下載的防濫用限制。

PDF 測試驗證實際 A4 頁數、可選取文字、兩語詞彙、分階段及教師資料隔離、字形／字型保留，並輸出實際 PDF 頁面及灰階資料圖到 `/tmp/vl1-paper-review` 供視覺檢查。

材料 v2：文字作答區統一兩行；A、C 首頁各保留一次姓名欄；句子填空使用句內圈選；清澈試管以細液面線及淺色液體顯示液位，沒有增加油層或數值資料。

材料 v3（舊版）：與 VL 同步新增實驗前提定義與「簡單繪畫、清楚標示」提醒；兩語均在相同位置以灰色小字顯示。原 A3＋A4 合併成新 A3，原 B1＋B2 合併成新 B1、原 B3＋B4 合併成新 B2，原 C1＋C2 合併成新 C1，反思保留在新 C2。繪圖框高 35 mm，四組基本結果並排；學習重點與乳化圖並排，化學結構圖置於下方。保留所有題目、提示、選項及兩行文字作答區，縮排後的中英文頁面均檢查溢出及實際 PDF。題目內容版本為 VL1-ui3-paper2，配分及學生紀錄格式保持原有設定。

其他 VL 可參考 [修訂後的跨 VL 紙本提示詞](../docs/CROSS_VL_PAPERWORK_PROMPT.md)，按題材及實際內容安排合併頁面。

材料 v4：改為原 A1＋A2 合併成新 A1（情境、初步觀察、假說及變量）；新 A2 只有實驗前提與對照組；新 A3 為獨立裝置設計頁，繪圖框高 140 mm，文字設計仍放在框下並保留兩條橫線。B、C 的合併安排保持 v3 的設定，總頁數仍為學生 7 頁、完整教師 14 頁。中英文各自檢查全部題目／選項、實際大繪圖框、內容溢出及頁尾間距。題目內容版本仍為 VL1-ui3-paper2。
