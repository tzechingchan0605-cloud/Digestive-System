請為這個 VL 設計並實作「教師下載紙本對照組工作紙 PDF」功能，供研究對照組使用。先檢查現有程式、題目與本聊天／儲存庫提供的研究 proposal；不得只按題材重寫一份相似工作紙。若未有 proposal 或缺少關鍵程序，清楚指出，先完成可獨立核對的部分，不宣稱已符合未見過的要求。若本聊天仍要求先審閱框架，先交框架與介面預覽，再按確認後的範圍實作。

本研究 proposal 已確認：4.1 對照組使用 identical scenarios, static data plots, and problem prompts；4.3.2 兩組完成四週相同概念與問題的模組，紙本以 static diagrams and pre-rendered data tables 代替互動模擬，活動在正式授課前進行。每週工作紙不包含或改寫 Week 0／四週後的正式 10 題 SPSAI、4 題 CKT 前後測，也不把實驗組專用的後測意見題／訪談加入對照組材料。學校是 CMI，預設繁中並保留該 VL 的英文版。單次活動時間、分冊頁數及回收方法未在 proposal 明定，需按共同研究程序處理。

1. **題目一致。** 工作紙與目前 VL 的題幹、提示、所有選項、單選／多選規則、材料數量、研究情境、實驗條件、圖像資料、學習重點及反思逐項對照。句子填空的下拉選單改為句內括號列出相同選項，學生圈選每組一項；多選使用複選方格。文字作答及修訂欄統一只提供兩條橫線；繪圖區保留清楚、有足夠空間作簡單標示的繪圖框，可調整尺寸配合合併頁面。不能新增、刪除、改難度、先給答案或恢復已刪題目。保持同一探究次序。行政資料／修訂記錄欄不是新增評分題。

   在 VL 與紙本的裝置繪圖區同步加入灰色小字：「不用精緻地繪畫所有特徵，簡單繪畫並標示清楚便可。」在實驗前提／假設題下同步加入灰色小字：「假設是指未經證實而被視為正確的條件，用於確保實驗結果的有效性。」保留原有題幹及提示；英文版分別用 "You do not need to draw every detail carefully. A simple drawing with clear labels is enough." 與 "An assumption is a condition we have not proved but take as true, to help make the experiment results valid."，其餘文字沿用該 VL 的映射。

2. **依研究程序分冊。** 建議 A「情境與原始設計」、B「實驗資料、分析與結論」、C「學習重點及反思」、D「教師指引、參考答案與評分準則」。按本 VL 及 proposal 的實際階段調整。A 不含結果；B 提供同一靜態資料，但觀察表及選擇題不預填；C 在收取／固定原探究答案後才發；D 只供教師。完整套裝供教師列印分發，不能整套一次派學生。各冊新頁開始，可獨立下載及列印。

3. **等量資料與合理界限。** 使用與 VL 一致的裝置、條件、靜態實驗圖或資料，學生自行判讀。資料表可預先印裝置、條件及原始量度／圖像資料，但不要預填待評的觀察判讀、計算、圖點、結論或反思。分清原始資料與學生要完成的答案；不能把必要原始數據也留空。不要增加 VL 沒有量度的數值、速度或圖表。若 proposal 指定實體實驗，按其程序處理，不自行改成靜態資料。說明數位操作與紙本閱讀的處理差異，不宣稱兩者所有操作完全等同。

4. **保留原始證據。** 原始假說、理由與設計在首次讀資料前固定保存；後續修訂另外保存，不能擦除原始版本。第一次觀察與最後修改可分開記錄。學生在反思時能參閱原始假說副本，不要求憑記憶重寫，也不捏造紙本操作事件／點擊數。教師指引寫清楚收取／備份及派發次序。

5. **教師界面。** 現有教師登入儀表板新增「下載紙本對照組工作紙 PDF」。登入即可使用，不要求先完成示範。點擊後可選繁中／英文、查看題目版本、材料版本及各冊頁數、預覽、下載完整教師列印套裝或各分冊。學生介面不顯示，處理函式亦檢查現有教師模式。不增加可刪題、加提示或改難度的設定。材料語言選擇不清空探究或改變學生答案。

6. **兩種語言。** 沿用這個 VL 現有中文／英文映射與教師批准的中文支援詞彙。中文版只用繁體中文；英文版只為已批准詞彙附括號繁體中文，其餘指示使用簡單英文。不能從其他題材直接移入詞彙或擴大清單。學生身份和自由作答空白；材料不能帶入真實學生或教師個資。

7. **真正的可下載 PDF。** 建議由共享內容及獨立紙本模板，在更新／建置時以 Chromium／Playwright 自動產出中英文 PDF，部署版本化材料；教師按鈕直接下載真正 PDF，不只開啟 HTML 或要求手動另存為 PDF。如採其他方式，須同樣保持中文／英文字型、科學符號、圖片及分頁正確，不以模糊長截圖充當 PDF。A4 文字作答區統一兩行、繪圖框在文字設計框前、同題選項合理同頁、圖片／表格不裁切。完整套裝的姓名／班別及學號欄只印在 A、C 首頁，不在每頁重複。若有液體圖，液面界線需清楚可見，不能讓清澈液體與白底混在一起；不要改變液量或加入原本沒有的油層。做黑白列印檢查，不能只靠顏色判讀資料；若必須彩印，清楚注明。

   **縮排及合併頁面。** 參照 VL1 最新排版：原 A1＋A2（情境、初步觀察、假說及變量）合併一頁；實驗前提與對照組放下一頁，裝置設計獨立一頁，繪圖框以 VL1 的 140 mm 高作參考，文字設計保留在框下；原 B1＋B2（基本實驗圖與觀察表）合併一頁；原 B3＋B4（結論與熱處理延伸）合併一頁；原 C1＋C2（學習重點、兩幅概念圖及證據界限）合併一頁，反思另保留下一頁。可調整結果圖及情境圖的大小、減少邊距／間距，使用並排圖或圖文配置；裝置繪圖維持獨立頁及充足作畫空間；不能省略問題、選項、提示、資料或作答橫線，也不能縮到科學結構／液面／圖表標示看不清。先按這個 VL 原頁面實際內容定位對應部分，沒有熱處理則保留該 VL 本來的延伸內容，不加入消化系統題目。若所需內容無法在清楚可讀的前提下放同頁，指出具體頁面及原因，不以裁切或極小文字強行塞入。VL1 合併後為 A 3 頁、B 2 頁、C 2 頁、D 7 頁，學生 7 頁、完整教師套裝 14 頁；其他 VL 頁數依題目及資料實際長度決定。中英文分別檢查排版，不假設中文能放下就代表英文也能。

8. **同一內容來源。** VL 與紙本共用題目 ID、題幹、提示、選項 ID、材料、結果／資料與學習重點；不要手抄維護另一份易過期的題目。需要重構時保留原答案 ID、紀錄兼容及舊學生原文。紙本選項在同一材料版本固定並平衡位置；與 VL 保持相同選項內容。若研究要求排序匹配，使用共同版本／種子而不是讀取某個學生狀態。輸出 manifest，記錄題目／材料版本、語言、選項順序、頁數與檔案；VL 更新時自動重建 PDF，版本不一致阻止部署。

9. **檔名及隔離。** 空白材料使用 `VL編號_紙本對照組_分冊_語言_版本.pdf` 等統一格式。保留既有學生完成報告命名功能。生成、預覽與下載不能建立學生探究、寫入本機紀錄／雲端、排隊同步、修改學生答案、示範、計時或事件，不能改教師 Excel。不要因這項功能要求新 Apps Script 收集端。學生分冊不含 ✓／✕、參考答案或能力／知識數字分數。

10. **評分與研究。** D 沿用這個 VL 的客觀參考答案與人工評分準則；原始合理可測試假說不因猜錯扣分。保留活動 rubric 初稿標記，不宣稱已經驗證；與 proposal 的 SPSAI／CKT 等量表分開。紙本不能用完成率、用時或模擬點擊數直接換算能力。需研究者確認跨組證據與活動程序可比性。

11. **有意義的驗證及交付。** 自動檢查逐題文字／提示／選項／材料一致、所有實驗資料與結果一致、階段及答案不提早洩露、兩語 PDF 真正可下載且字型／分頁／頁碼／檔名正確；逐頁檢查合併內容全部存在、兩行作答區、姓名欄位置、內容沒有上下或左右溢出、液面清楚。渲染實際 PDF 檢查中英文合併頁及灰階圖，不只看 HTML 或頁數。驗證教師入口、學生無入口、下載前後學生紀錄／雲端 payload／Excel／示範不變。另驗證共享題目更新會重建材料及排除舊 PDF。更新下載面板、manifest 及 README 的頁數、頁碼範圍、版本與檔名，說明實際通過的測試、未驗證項目、派發方法及尚需核對的 proposal 要求。按本聊天已授權的範圍實作並更新 GitHub，不停在建議清單。
