# VL1 英文版候選詞彙校對清單

以下是「未知消化液 X 與 Y」VL1 的暫定詞彙，尚未獲教師確認。請校對英文及繁體中文用語，並指出哪些英文詞不需要括號中文支援、哪些需要補充。這份清單用於介面閱讀支援，不改變題目內容、答案識別值、教師 Excel 或評分。

英文版一般按鈕、日常用語及普通句子只用英文；下面列出的較難詞彙暫採 `英文 (繁體中文)`。大小寫及單複數會按句子調整。中文版只使用中文說明，化學式、單位、裝置代號及學生自行輸入的原文照常保留。
