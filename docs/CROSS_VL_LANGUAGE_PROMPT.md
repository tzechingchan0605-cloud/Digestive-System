# 跨 VL 語言切換提示詞

請把以下整段貼給負責其他虛擬實驗室的聊天機械人。以該 VL 的原始程式、探究題材及資料格式為準；保留已完成的雲端儲存與教師功能。

---

請直接檢查並修改這個 VL 的程式，加入與其他 VL 一致的中文／英文切換功能。完成程式、測試及 README 說明後，依本聊天已授權的流程更新儲存庫，不要停在建議清單。

1. 在頁面右上角加入一直可見的語言切換按鈕；桌面及手機版均可操作，不能遮擋內容、登入或教師控制。每次重新載入頁面預設為繁體中文，不能從 localStorage、舊探究或瀏覽器語言還原為英文。按鈕要在登入頁、學生探究及教師示範時可用。

2. 按鈕開啟可取消的代碼輸入介面。輸入 `CMI` 切換中文，輸入 `EMI` 切換英文；忽略前後空白，按大寫代碼檢查。錯誤代碼顯示清楚提示，取消或錯誤輸入保留目前語言和全部作答。不要把代碼填入學生答案、操作事件或教師密碼欄。代碼只是課堂切換代碼，會寫在公開 README，不要宣稱為安全登入機制。

3. 中文版的介面說明使用繁體中文，不附英文翻譯（保留必要的化學式、數學符號、單位、裝置代號及學生原文）。英文版使用英文，只有教師已批准的詞彙才在英文後附括號繁體中文。不得自動為所有科學或探究用語加中文；hypothesis、assumption、fair test、independent variable、dependent variable、controlled variable、control group、inference、evidence 等一般探究用語不附中文。非生物專有詞彙的指示使用簡單英文，例如用 experiment setup 代替 apparatus；在意思準確的情況下，以 idea to test 解釋 hypothesis，或在預測題用 prediction。不能為了簡化而改變科學意思。變量分類保留正式名稱，附簡單英文定義：independent variable 是「the factor changed on purpose」、dependent variable 是「the result you measure or observe」、controlled variables 是「the factors kept the same」。生物詞彙保持科學準確。下列 11 組消化系統詞彙已批准，但只在本 VL 本身有該概念時使用，不能把消化概念加進其他題材。若本 VL 是其他題材，請先提供該題材的候選詞彙讓教師選擇；未獲批准的詞彙先只用英文。可先完成切換、翻譯、儲存及測試等獨立工作，中文支援清單須集中維護。

4. 翻譯範圍包括登入欄位、四階段探究、題目、選項、提示、材料、圖例、觀察表、熱處理／延伸實驗、學習重點、反思、狀態訊息、錯誤訊息、按鈕、確認視窗、列印／PDF，以及動態新增的文字。每個 input 和 textarea 的 placeholder 都要翻譯，例如中文「我觀察到……」在英文版顯示「I observe that…」；只翻譯 placeholder 等介面屬性，不能改寫輸入欄的 value 或學生已填文字。圖片或 SVG 中的題材文字也需有對應英文版本；替代文字、ARIA 標籤及唯讀報告需一致。每次重繪、動畫結束、觀察確認及同步狀態更新後仍須保持所選語言。使用適合英文字長度的手機及列印排版，不以整頁文字置換來修改學生文字。

5. 語言只是呈現設定。切換時不能重新登入、重新開始探究、重排已固定的選項、取消正在進行的實驗、清空欄位或繪圖，也不能改變作答鎖定、反思提交、計時、PDF 門檻、待同步狀態及教師示範隔離。學生姓名、班別、電郵、理由、文字設計、反思和圖片保留原文，不自動翻譯。

6. 保持原有語言無關的答案識別碼、選項 `value`、模組識別碼、紀錄 ID、資料欄位、儲存鍵、評分映射、原始／最終快照、事件內容及雲端通訊協議。不能用英文選項文字取代原先的儲存值。若既有紀錄本身以中文文字作為作答值，必須維持相容，以呈現映射提供英文。切換語言本身不能新增探究、改寫原始作答、觸發額外學生紀錄或清除待同步佇列。

7. 跨瀏覽器集中儲存、重試補傳、同電郵多次探究及教師載入全班紀錄必須繼續正常運作。教師 Excel 的工作表名、欄名、參考答案、狀態、評分說明及公式維持繁體中文；英文介面作答仍輸出相同標準作答值。開放題保留學生輸入原文。學生／教師 PDF 按目前所選語言呈現題目及參考說明，保持原有是否准許列印的規則，不把教師評分加入學生 PDF。

8. README 記錄：預設繁體中文、右上角切換方法、中文代碼 `CMI`、英文代碼 `EMI`、代碼只是課堂用途、一般指示使用簡單英文、輸入欄提示文字需翻譯而學生原文不翻譯、語言不影響儲存與教師 Excel，以及教師已批准的中文支援詞彙清單。保留原有部署、雲端、教師登入及測試說明。

9. 加入有意義的隔離測試，測試資料不可上傳正式收集端。至少驗證：初次載入及重新整理均為中文；正確兩種大寫代碼、錯誤及取消；手機右上角按鈕及輸入介面；登入前後切換；已選客觀答案及已填自由文字不變；空白及已填寫的 input／textarea 均更新 placeholder 而不改 value；繪圖與執行中的實驗不變；動態題目與同步訊息保持英文；英文版只有已批准詞彙帶中文支援；探究和反思鎖定不變；PDF 的兩種語言；刷新後原有紀錄可保留；切換前後相同探究的本機資料及雲端 payload 一致；英文與中文介面以相同答案匯出的教師 Excel 一致，包括作答值、公式、圖片和人工評分空白狀態。比較可忽略匯出封裝時間等與內容無關的差異，不可忽略答案或評分差異。

10. 交付時簡述修改和實際測試結果，確認採用的教師批准詞彙清單，再按既有 GitHub 授權更新。其他題材若尚未獲詞彙批准，另列候選供教師選擇，不先把候選全部加進英文介面。若英文環境仍有中文文字，清楚區分指定詞彙支援、學生原文與尚未完成的翻譯。
