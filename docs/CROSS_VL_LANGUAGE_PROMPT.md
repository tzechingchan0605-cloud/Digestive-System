# 跨 VL 語言切換提示詞

請把以下整段貼給負責其他虛擬實驗室的聊天機械人。以該 VL 的原始程式、探究題材及資料格式為準；保留已完成的雲端儲存與教師功能。

---

請直接檢查並修改這個 VL 的程式，加入與其他 VL 一致的中文／英文切換功能。完成程式、測試及 README 說明後，依本聊天已授權的流程更新儲存庫，不要停在建議清單。

1. 在頁面右上角加入一直可見的語言切換按鈕；桌面及手機版均可操作，不能遮擋內容、登入或教師控制。每次重新載入頁面預設為繁體中文，不能從 localStorage、舊探究或瀏覽器語言還原為英文。按鈕要在登入頁、學生探究及教師示範時可用。

2. 按鈕開啟可取消的代碼輸入介面。輸入 `CMI` 切換中文，輸入 `EMI` 切換英文；忽略前後空白，按大寫代碼檢查。錯誤代碼顯示清楚提示，取消或錯誤輸入保留目前語言和全部作答。不要把代碼填入學生答案、操作事件或教師密碼欄。代碼只是課堂切換代碼，會寫在公開 README，不要宣稱為安全登入機制。

3. 中文版的介面說明使用繁體中文，不附英文翻譯（保留必要的化學式、數學符號、單位、裝置代號及學生原文）。英文版以英文呈現，部分較難的科學及探究詞彙在英文後附繁體中文括號，例如 `independent variable（獨立變量）`、`control group（對照組）`。請先根據這個 VL 整理候選英中詞彙，提供教師校對是否需要中文支援；在可獨立完成的功能先採合理暫定清單，並讓清單集中維護，待教師回覆後容易修改。不要把其他 VL 的專有內容照搬進來。

4. 翻譯範圍包括登入欄位、四階段探究、題目、選項、提示、材料、圖例、觀察表、熱處理／延伸實驗、學習重點、反思、狀態訊息、錯誤訊息、按鈕、確認視窗、列印／PDF，以及動態新增的文字。圖片或 SVG 中的題材文字也需有對應英文版本；替代文字、ARIA 標籤及唯讀報告需一致。每次重繪、動畫結束、觀察確認及同步狀態更新後仍須保持所選語言。使用適合英文字長度的手機及列印排版，不以整頁文字置換來修改學生文字。

5. 語言只是呈現設定。切換時不能重新登入、重新開始探究、重排已固定的選項、取消正在進行的實驗、清空欄位或繪圖，也不能改變作答鎖定、反思提交、計時、PDF 門檻、待同步狀態及教師示範隔離。學生姓名、班別、電郵、理由、文字設計、反思和圖片保留原文，不自動翻譯。

6. 保持原有語言無關的答案識別碼、選項 `value`、模組識別碼、紀錄 ID、資料欄位、儲存鍵、評分映射、原始／最終快照、事件內容及雲端通訊協議。不能用英文選項文字取代原先的儲存值。若既有紀錄本身以中文文字作為作答值，必須維持相容，以呈現映射提供英文。切換語言本身不能新增探究、改寫原始作答、觸發額外學生紀錄或清除待同步佇列。

7. 跨瀏覽器集中儲存、重試補傳、同電郵多次探究及教師載入全班紀錄必須繼續正常運作。教師 Excel 的工作表名、欄名、參考答案、狀態、評分說明及公式維持繁體中文；英文介面作答仍輸出相同標準作答值。開放題保留學生輸入原文。學生／教師 PDF 按目前所選語言呈現題目及參考說明，保持原有是否准許列印的規則，不把教師評分加入學生 PDF。

8. README 記錄：預設繁體中文、右上角切換方法、中文代碼 `CMI`、英文代碼 `EMI`、代碼只是課堂用途、自由文字不翻譯、語言不影響儲存與教師 Excel，以及詞彙清單校對位置。保留原有部署、雲端、教師登入及測試說明。

9. 加入有意義的隔離測試，測試資料不可上傳正式收集端。至少驗證：初次載入及重新整理均為中文；正確兩種代碼、錯誤及取消；手機右上角按鈕及輸入介面；登入前後切換；已選客觀答案及已填自由文字不變；繪圖與執行中的實驗不變；動態題目與同步訊息保持英文；探究和反思鎖定不變；PDF 的兩種語言；刷新後原有紀錄可保留；切換前後相同探究的本機資料及雲端 payload 一致；英文與中文介面以相同答案匯出的教師 Excel 一致，包括作答值、公式、圖片和人工評分空白狀態。比較可忽略匯出封裝時間等與內容無關的差異，不可忽略答案或評分差異。

10. 交付時簡述修改和實際測試結果，列出待教師校對的候選詞彙及其繁體中文翻譯，再按既有 GitHub 授權更新。若英文環境仍有中文文字，清楚區分指定詞彙支援、學生原文、必要代號與尚未完成的翻譯。

候選詞彙請按題材整理，以下只是通用起點：

| 英文 | 繁體中文 |
| --- | --- |
| hypothesis | 假說 |
| assumption | 實驗前提 |
| prediction | 預測 |
| fair test | 公平測試 |
| independent variable | 獨立變量 |
| dependent variable | 因變量 |
| controlled variable | 控制變量 |
| control group | 對照組 |
| experimental group | 實驗組 |
| apparatus | 實驗裝置 |
| qualitative observation | 定性觀察 |
| inference | 推論 |
| evidence | 證據 |
| limitations of evidence | 證據界限 |
| reflection | 反思 |

請加上這個 VL 實際使用的生物、化學或物理詞彙，核對課程用語，並讓教師決定哪些英文詞需要括號中文支援。
